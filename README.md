# Cronometro Flutter

Cronometro Flutter e um app simples de cronometro com suporte a voltas e modo flutuante. O foco e oferecer um controle rapido do tempo, com uma interface direta e leve.

## Recursos

- Iniciar, pausar e zerar o cronometro
- Registro de voltas
- Modo flutuante (overlay)
- Tela principal com visor destacado

## Tecnologias

- Flutter
- Dart
- Provider (gerenciamento de estado)

## Requisitos

- Flutter SDK instalado
- Dispositivo fisico ou emulador

## Como rodar

```bash
flutter pub get
flutter run
```

## Build

```bash
flutter build apk
```

## Testes

```bash
flutter test
```
